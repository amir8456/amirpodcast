# Studio Video Editor

הפרוטוקול המלא, כולל מילון ביטויי הקסם, שער האישורים והלקחים המצטברים, נמצא ב-`CLAUDE.md` שבשורש הפרויקט. הוא מקור האמת היחיד.

לפני כל עבודה על סרטון:
1. קרא את `CLAUDE.md` במלואו, ובמיוחד את הסעיף "לקחים והעדפות אישיות".
2. סרוק את התיקייה לאיתור נכסי מותג (לוגו, פונטים, צבעים, וידאו, אודיו, מודלי 3D).
3. פעל לפי שער האישורים: תסריט וסטוריבורד, ואז עצירה עם המשפט *"האם התסריט והכיוון הוויזואלי מאושרים ליציאה לביצוע?"*. אין קוד ואין רינדור לפני אישור מפורש.
4. אחרי פידבק: עדכן את הלקחים ב-`CLAUDE.md` (לא כאן), ובצע commit ו-push.
